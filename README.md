# Devtosh SuperBazaar

**Curated fashion, smartphones, mobile accessories, footwear, and lifestyle affiliate discovery platform & editorial blog.**

🌐 **Live Website:** [https://devtoshsuperbazaar.github.io](https://devtoshsuperbazaar.github.io)

## Overview

Devtosh SuperBazaar is a responsive, editorial discovery platform connecting shoppers across India with handpicked fashion, trending ethnic wear, smart budget electronics, mobile accessories, footwear, and lifestyle essentials.

### Key Features
- **Editorial Discovery Catalog:** Handpicked collections spanning Women's Ethnic Wear, Men's Fashion, Western Styles, Footwear, Smartphone Accessories, and Everyday Deals.
- **SSG-Prerendered Blog:** Fast, SEO-optimized style guides with Schema.org `BlogPosting` structured data, automatic reading-time calculation, and inline product recommendation cards.
- **Admin Writing Studio:** Intuitive editorial authoring panel featuring an interactive Markdown toolbar, one-click link insertion modal, real-time draft/live previewing, and store product affiliate linkers.
- **Search & SEO Optimization:** SearchAction schema, OpenGraph social sharing preview cards, canonical URLs, automated XML sitemap (`/sitemap.xml`), and `robots.txt`.
- **Responsive Brand Design:** Devtosh SuperBazaar signature palette with high contrast and smooth dark/light mode switching.
